Outbox 消息表 · 可靠投递

订单与 Outbox 同事务落库；PENDING → SENT（发 visitor.reserve.*）→ REPLIED / FAILED。

三源对账（模拟）

Redis 分段扣减量 == DB 订单数 == 访客预约成功数；退款中短暂不一致属正常。

六项设计决策速览

D1 分段库存

单日库存拆 N 段打散热点 key，限购标记与扣减在同一 Lua 脚本原子完成。

D2 本地 JWT 验签

缓存访客系统 JWKS 公钥，抢票期纯本地验签，主链路 0 远程调用。

D3 接口 Outbox 化

扣减成功写 Redis Stream pending，消费者单事务 INSERT 订单 + Outbox。

D4 退款熔断降级

NORMAL/DEGRADED 全局态：降级期不退款、只重发、文案「预约确认中」。

D5 统一开放窗口

放票与校验共用 OPEN_DAYS，从 now() 起算，根治 off-by-one。

D6 幂等契约

messageId + externalOrderNo 双幂等键，回执侧非 RESERVING 直接忽略。
