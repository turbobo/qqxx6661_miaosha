2持签下单

携带 verifyHash 调用下单接口，凭证不合法直接拒绝

原理：把抢购接口变成「一次性凭证」

脚本刷单最怕两件事：接口地址写死可直接调用、调用频率不受限制。本方案两步破解：

① 先调 verify-hash 领凭证（服务端校验时段与用户，hash = MD5(盐 + sid + userId) 存 Redis）；② 下单接口必须携带合法 verifyHash 才放行——脚本连 hash 都拿不到，就无从刷起；③ 限频版再叠加「60 秒窗口内访问超 3 次即封禁」，即便脚本持有合法 hash 也无法高频下单。

试试：不领通行证直接点「持签下单」会被拒绝；连续多点几次「限频版」会触发频率限制封禁。
